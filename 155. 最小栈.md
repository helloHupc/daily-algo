## 题目描述

设计一个支持 `push` ，`pop` ，`top` 操作，并能在常数时间内检索到最小元素的栈。

实现 `MinStack` 类:

- `MinStack()` 初始化堆栈对象。
- `void push(int val)` 将元素val推入堆栈。
- `void pop()` 删除堆栈顶部的元素。
- `int top()` 获取堆栈顶部的元素。
- `int getMin()` 获取堆栈中的最小元素。

**示例 1:**

**输入：** 
`["MinStack","push","push","push","getMin","pop","top","getMin"]`
`[[],[-2],[0],[-3],[],[],[],[]]`

**输出：** 
`[null,null,null,null,-3,null,0,-2]`

**解释：**
MinStack minStack = new MinStack();
minStack.push(-2);
minStack.push(0);
minStack.push(-3);
minStack.getMin();   --> 返回 -3.
minStack.pop();
minStack.top();      --> 返回 0.
minStack.getMin();   --> 返回 -2.

**提示：**

- `-231 <= val <= 231 - 1`
- `pop`、`top` 和 `getMin` 操作总是在 **非空栈** 上调用
- `push`, `pop`, `top`, and `getMin`最多被调用 `3 * 104` 次

## 解题思路 ：

引入一个辅助栈，用来处理最小值在常数时间检索问题。


## 代码实现

## PHP 解法

```php
class MinStack {
    /**
     */
    private $stack;
    private $mini_stack;
    function __construct() {
        $this->stack = [];
        $this->mini_stack = [];
    }
  
    /**
     * @param Integer $val
     * @return NULL
     */
    function push($val) {
        array_push($this->stack,$val);
        $mini = end($this->mini_stack);
        if ($val <= $mini || $mini === false){
            array_push($this->mini_stack,$val);
        }
    }
  
    /**
     * @return NULL
     */
    function pop() {
        if(array_pop($this->stack) == end($this->mini_stack)){
            array_pop($this->mini_stack);
        }
    }
  
    /**
     * @return Integer
     */
    function top() {
        return end($this->stack);
    }
  
    /**
     * @return Integer
     */
    function getMin() {
        return end($this->mini_stack);
    }
}

/**
 * Your MinStack object will be instantiated and called as such:
 * $obj = MinStack();
 * $obj->push($val);
 * $obj->pop();
 * $ret_3 = $obj->top();
 * $ret_4 = $obj->getMin();
 */
```

## Go 解法

```go
type MinStack struct {
    Stack []int
    MiniStack []int
}


func Constructor() MinStack {
    return MinStack{
        Stack : []int{},
        MiniStack : []int{},
    }
}


func (this *MinStack) Push(val int)  {
    this.Stack = append(this.Stack,val)
    if len(this.MiniStack) == 0 || val <= this.MiniStack[len(this.MiniStack)-1] {
        this.MiniStack = append(this.MiniStack,val)
    }
}


func (this *MinStack) Pop()  {
    top := this.Stack[len(this.Stack)-1]
    this.Stack = this.Stack[:len(this.Stack)-1]
    if top == this.MiniStack[len(this.MiniStack)-1] {
        this.MiniStack = this.MiniStack[:len(this.MiniStack)-1]
    }
}


func (this *MinStack) Top() int {
    return this.Stack[len(this.Stack)-1]
}


func (this *MinStack) GetMin() int {
    return this.MiniStack[len(this.MiniStack)-1]
}


/**
 * Your MinStack object will be instantiated and called as such:
 * obj := Constructor();
 * obj.Push(val);
 * obj.Pop();
 * param_3 := obj.Top();
 * param_4 := obj.GetMin();
 */
```
## 关键点

引入一个辅助栈，用来处理最小值在常数时间检索问题。

## 复杂度分析

- 时间复杂度 O(1) ： 使用常数时间。
- 空间复杂度 O(N) ： 要维护两个N个元素的栈空间。
